# Scientific route

The question is whether an autonomous quantum clock's precision remains useful after its actual speed must be learned with a finite reference that is then removed.

The central result is an operational obstruction. Even a noiseless source with one unknown accessible speed needs sufficiently many classical reference events to estimate physical elapsed time. The finite quantum construction shows when paying that calibration bill and reusing it still preserves an advantage.

Read the model first. The converse needs the single unknown accessible-speed premise and the classical-reference restriction; the constructive protocol adds mixing and positive-current assumptions. Their domains should not be confused.

The source and reference are effective open-system models. Source thermal resets are retained in the dynamics; detector amplification, reference rate certification, register preparation/erasure and a uniform microscopic implementation are separate declared resources or limitations.
